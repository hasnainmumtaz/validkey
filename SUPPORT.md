# Getting help

Read the [README](README.md) and run `validkey --help` first. Run a failed check without `--quiet` to see its diagnostic. Network and permission failures do not necessarily mean the key is invalid.

Search [existing issues](https://github.com/hasnainmumtaz/validkey/issues). Use the bug template for unexpected behavior and the feature template for enhancements or providers. General usage questions can use a blank issue with a clear title.

Include your operating system, Node.js and Validkey versions, provider, expected behavior, and a sanitized error message. Never include keys, environment dumps, or authorization headers. Account, billing, quota, and credential-revocation questions belong with the provider's support.

For vulnerabilities, follow [SECURITY.md](SECURITY.md). For conduct concerns, use the private contact in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). Support is best-effort with no guaranteed response time.
